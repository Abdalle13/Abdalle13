## 👨‍💻 About Me

I'm a **Full-Stack Developer based in Mogadishu, Somalia**, and a **BSc Computer Science graduate** from **Jamhuriya University of Science & Technology (JUST)**.

I enjoy building complete web applications — from designing the user interface and developing backend APIs to structuring databases and connecting the different parts of a system.

During my studies, I designed and developed **AgriSense**, a smart agriculture platform built around a **microservices architecture**. The project combined web technologies with IoT and machine learning to address real-world agricultural challenges.

I'm particularly interested in writing **clean, maintainable code**, building useful applications, and continuously improving my understanding of software development.

* 💻 **Core Stack:** React, JavaScript, TypeScript, Node.js, Express.js, MongoDB, Tailwind CSS
* 📐 **Focus Areas:** Full-Stack Development, REST APIs, Database Design, Authentication & Authorization
* 🧩 **Architecture:** Modular Web Applications & Microservices Experience through AgriSense
* 🎓 **Education:** BSc in Computer Science — JUST
* 📍 **Based in:** Mogadishu, Somalia
* 🤝 **Open To:** Junior Developer Roles, Remote Opportunities, Freelance Projects & Collaborations

A smart agriculture platform developed as my final-year project to support agricultural decision-making through technology.

The system uses a **microservices architecture** and integrates real-time data, web dashboards, and AI-based functionality to address agricultural challenges.

**Key Areas:**

* 🌱 Real-time soil nutrient monitoring
* 🤖 Crop disease diagnosis using CNN-based deep learning
* 🌦️ Weather prediction
* 📊 Real-time monitoring dashboards
* 🧩 Microservices-based backend architecture
* 🌍 Automated Somali-language agricultural guidance

**Technologies:** React • Node.js • Express.js • MongoDB • REST APIs • IoT • CNN • Machine Learning
