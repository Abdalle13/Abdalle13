## 🚀 Featured Project — AgriSense 🌾

<div align="center">

> **An Integrated Precision Agriculture System** — Built for smallholder farmers in Afgoye, Somalia

</div>

| Component | Technology | Result |
|---|---|---|
| 🔬 **Crop Disease Diagnostics** | CNN (MobileNetV2) — Transfer Learning | **97.92% accuracy** |
| 📡 **IoT Soil Telemetry** | ESP32 + RS485 NPK + DHT11 Sensors | Real-time telemetry every 30s |
| 🤖 **AI Advisory Engine** | Google Gemini API Integration | Somali-language treatment guidance |
| ⚡ **Real-Time Interface** | Socket.io + React.js + Tailwind CSS | Sub-second real-time sync |
| 🌐 **Backend Microservices** | Node.js + Express + FastAPI + MongoDB | 26 production REST endpoints |
| 📊 **Dataset Architecture** | PlantVillage & Custom Agricultural Sets | 39,264 images · 27 classes |
