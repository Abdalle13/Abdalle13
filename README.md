## 👨‍💻 About Me

I'm a **Full-Stack Developer** based in **Mogadishu, Somalia**, passionate about building practical software that solves real-world problems.

I recently graduated with a **BSc in Computer Science** from **Jamhuriya University of Science & Technology (JUST)**. I focus on building complete, end-to-end web applications—from designing responsive frontends and RESTful APIs to structuring scalable MongoDB database schemas.

* 💻 **Core Tech Stack:** React, Node.js, Express.js, MongoDB, TypeScript, Tailwind CSS
* 📐 **Focus Areas:** Web Application Architecture, REST API Design, Database Management
* 🤝 **Open To:** Junior / Entry-Level Full-Stack Developer roles, Remote opportunities, & Freelance projects

## 🚀 Featured Projects

### 🌾 AgriSense — Smart Agriculture Platform

An integrated smart agriculture system developed to support farmers through technology-driven monitoring, diagnosis, and decision-making.

The platform combines a **microservices architecture**, real-time data monitoring, and machine learning capabilities to address practical agricultural challenges.

**Highlights:**

* 🌱 Real-time soil nutrient monitoring
* 🤖 CNN-based crop disease diagnosis
* 🌦️ Weather prediction
* 📊 Web-based monitoring dashboards
* 🧩 Microservices-based backend architecture
* 🌍 Somali-language agricultural guidance

**Tech Stack:** React • Node.js • Express.js • MongoDB • REST APIs • IoT • CNN • Machine Learning

**Highlights:**

* 👨‍👩‍👧 Parent and student portals
* 📋 Attendance management
* 📝 Exams and assessments
* 📊 Academic results and report cards
* 💰 Fees and installment management
* 🔐 Role-Based Access Control (RBAC)
* 📅 Timetable management
* 📈 Administrative dashboards
* 📄 PDF reports
* 🔔 Notifications

**Tech Stack:** React • Node.js • Express.js • MongoDB • Tailwind CSS • JWT • REST APIs

* 🔐 **Security** — Treating authentication, authorization, and user data seriously.
