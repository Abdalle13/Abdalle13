## 🚀 Featured Project — AgriSense 🌾

<div align="center">

> **An Integrated Precision Agriculture System** — Built for smallholder farmers in Afgoye, Somalia

</div>

| Component | Technology | Result |
|---|---|---|
| 🔬 **Crop Disease Detection** | CNN (MobileNetV2) — Transfer Learning | **97.92% accuracy** |
| 📡 **IoT Soil Monitoring** | ESP32 + RS485 NPK + DHT11 | Real-time data every 30s |
| 🤖 **AI Advisory** | Google Gemini API | Somali-language treatment plans |
| ⚡ **Real-Time Dashboard** | Socket.io + React.js | Updates under 1 second |
| 🌐 **Full Stack Platform** | Node.js + FastAPI + MongoDB | 26 REST endpoints |
| 📊 **Training Dataset** | PlantVillage + Mango Dataset | 39,264 images · 27 classes |
